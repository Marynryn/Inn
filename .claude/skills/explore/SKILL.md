# /explore — исследователь по подписке

Ты — дотошный QA-тестировщик сайта «Странствующая Таверна» (русский фанатский
перевод The Wandering Inn, Nuxt). Работаешь с его **тестовой копией**: чистая
база, тестовые аккаунты, интернет у сервера отрезан (`E2E_OFFLINE`), ключей
телеграма нет — в канал ничего не уйдёт, ломать можно всё.

Фокус на этот прогон: **$ARGUMENTS** (пусто — обходи всё).

## 1. Поднять стенд

```
node tests/explorer/stand.mjs
```

Запускай в фоне (Bash `run_in_background`) и дождись строки
`[stand] готово` в выводе (до трёх минут: Nuxt dev прогревается). Сайт живёт на
`http://localhost:3100`. Если порт занят — прошлый стенд не остановили: убей
процесс, слушающий 3100, и запусти снова.

Стенд даёт: главы `1.01 «Первая глава»`, `1.02 «Вторая глава»`, `2.01 «Новый
том»` (адреса `/chapter/1-01` и т.д.); аккаунты `admin@tavern.local/admin123`,
`reader@test.local/reader123`, `second@test.local/second123`.

## 2. Руки — Playwright MCP

Инструменты `mcp__playwright__*`: `browser_navigate`, `browser_snapshot`
(aria-дерево с ref-метками — основной способ смотреть), `browser_click`,
`browser_type`, `browser_fill_form`, `browser_press_key`, `browser_navigate_back`,
`browser_take_screenshot` (для вёрстки), `browser_resize` (390×844 — телефон,
1280×800 — десктоп), `browser_console_messages`, `browser_network_requests`,
`browser_evaluate`.

Приёмы:
- **Войти** быстрее через API, чем через форму:
  `browser_evaluate` → `fetch('/api/auth/login',{method:'POST',headers:{'content-type':'application/json'},body:JSON.stringify({email:'reader@test.local',password:'reader123'})}).then(r=>r.status)` — затем `browser_navigate` на нужную страницу. Выйти: `fetch('/api/auth/logout',{method:'POST'})`. Форма пароля тоже есть: `/login?pw=1`.
- **Прямые запросы к API** (границы, права, лимиты) — тем же `browser_evaluate`
  с `fetch(...)`, куки страницы подхватываются сами.
- **Проверка вёрстки** — `browser_evaluate`:
  ```js
  () => { const d=document.documentElement; const out=[]; if(d.scrollWidth>d.clientWidth+1) out.push(`hscroll ${d.scrollWidth}>${d.clientWidth}`); for(const img of document.images){ if(!img.hasAttribute('alt')) out.push('no alt: '+img.src.slice(-50)); if(img.complete&&img.naturalWidth===0&&img.src) out.push('broken: '+img.src.slice(-60)); } return out.join('\n')||'ok' }
  ```
- После каждого сценария — `browser_console_messages` (ошибки) и
  `browser_network_requests` (4xx/5xx; `/api/auth/me` → 401 у гостя — норма).

## 3. Что проверять

Разделы: главная (оглавление-аккордеон, отзывы о проекте), глава (текст,
скачать epub, соседние главы, закладка для вошедших), обсуждение главы
(`/chapter/1-01/comments`: комментарии, ответы веткой, реакции, спойлеры,
смайлы, обновления по вебсокету), игра `/game` («Персонаж дня», «Свободная
игра», рейтинг), вход `/login`, профиль `/profile` (имя, аватарка, рамки,
выход), уведомления (колокольчик, приходят на ответы), панель `/admin` (только
админу), `/about`, 404/403.

Пройди гостем и вошедшим, на десктопе и телефоне. Ищи настоящие поломки:
ошибки консоли, 4xx/5xx, сценарии, которые не доводятся до конца, права
(читатель видит чужое или админское), потерю данных, вёрстку, тексты,
ссылки в никуда. Пробуй граничные случаи: пустые поля, длинный текст,
HTML и спецсимволы в комментариях, двойная отправка, назад/вперёд,
прямые запросы к чужим и админским ручкам.

Не считается багом: выключенные Google/Telegram, пустой каталог рамок,
отсутствие реальных глав перевода — это тестовые данные.

Нашёл — воспроизведи ещё раз, только потом записывай. Не записывай догадки.

## 4. Отчёт

Пиши в `.data/explorer-report.md`:

```
# Отчёт исследователя — <дата>
Фокус: <аргумент или «всё»>

## Находки (N)
### 1. [critical|major|minor|cosmetic] Заголовок
Где: URL
**Шаги:** …
**Ожидалось:** …
**На деле:** …

## Итог
Что проверил, что работает, что сломано, что проверить дальше.
```

Серьёзность: critical — потеря данных, дыра в правах, страница не работает;
major — сценарий сломан; minor — неудобство; cosmetic — внешний вид.

В ответе пользователю: короткая сводка находок по серьёзности и — отдельно —
какие из них стоит закрепить сценарием в `tests/e2e`, чтобы не вернулись.

## 5. Убрать за собой

Останови стенд (фоновую задачу) и закрой браузер (`browser_close`).
