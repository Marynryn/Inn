# Демо-стенд и название сайта

Код сайта один на Таверну, демо-стенд и будущие сайты покупателей. Чем они
отличаются — задаётся переменными окружения, без правок кода и без пересборки.

## Название сайта и книги

По умолчанию везде Таверна. Другой сайт подменяет это переменными:

| Переменная | Что это | Где видно |
|---|---|---|
| `NUXT_PUBLIC_BRAND_SITE_NAME` | Название сайта | шапка, заголовки вкладок, превью ссылок |
| `NUXT_PUBLIC_BRAND_BOOK_NAME` | Название оригинала | «Фанатский перевод · …», заголовки глав, описания |
| `NUXT_PUBLIC_BRAND_HOME_DESCRIPTION` | Описание главной для поиска | `<meta name="description">` |
| `NUXT_PUBLIC_BRAND_ABOUT_DESCRIPTION` | Описание страницы «О проекте» | то же для /about |
| `NUXT_PUBLIC_BRAND_BOOK_ALT_NAMES` | Другие названия книги, через `\|` | разметка schema.org у главы |
| `NUXT_PUBLIC_BRAND_BOOK_GENRES` | Жанры, через `\|` | то же |
| `NUXT_PUBLIC_BRAND_BOOK_KEYWORDS` | Ключевые слова | то же |

Тексты главной, подвала, «О проекте», ссылки на телеграм и поддержку — это
настройки сайта, они правятся в панели администратора.

## Режим демо

`NUXT_PUBLIC_DEMO=true` включает демо-стенд:

- при первом запуске база наполняется выдуманной книгой «Девятый фонарь»
  (`server/utils/demo/book.ts`): главы, черновик, читатели, комментарии, закладка;
- на странице входа — кнопки «Войти администратором» и «Войти читателем»
  (логины в `shared/utils/demo.ts`), менять почту и пароль демо-админа нельзя;
- каждую ночь в 04:00 МСК стенд стирается и наполняется заново (задача `demo-reset`);
- сайт закрыт от поиска (`robots.txt` и `noindex`), IndexNow и подсчёт глав
  оригинала не работают, игра и персонажи спрятаны — они пока собраны под TWI.

Сброс стирает папку хранилища целиком, поэтому на адресах Таверны режим демо
не включится, даже если переменную поставить по ошибке (`isDemo()` в
`server/utils/demo/seed.ts`).

### Сервис на Railway

Отдельный сервис из этого же репозитория, со своим томом:

```
STORAGE_DIR=/data                  # том, смонтированный в /data
NUXT_SESSION_PASSWORD=<случайная строка от 32 символов>
NUXT_PUBLIC_SITE_URL=https://<адрес демо>
NUXT_PUBLIC_DEMO=true
NUXT_PUBLIC_BRAND_SITE_NAME=Девятый фонарь
NUXT_PUBLIC_BRAND_BOOK_NAME=The Ninth Lantern
```

Ключи телеграма, Google и Clarity демо не нужны — без них эти функции просто
выключены.
