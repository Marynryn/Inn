# Виртуальный тестировщик

Два уровня: **сценарии** (детерминированные, гоняются на каждый пуш) и
**исследователь** (агент на Claude, ищет то, чего в сценариях нет).

Оба поднимают сайт сами — на порту 3100, с пустой базой в `.data/e2e`. Боевая
база и `.env` не задействованы.

**Телеграм и внешний мир — отрезаны дважды.** Ключи телеграма и Google в
тестовом окружении пустые (`tests/e2e/serve.mjs`), а сверх того сервер
запускается с `E2E_OFFLINE=1`: плагин `server/plugins/offline-guard.ts`
подменяет `fetch` и обрывает любой запрос не на localhost ещё до сети. В канал
из тестов не уйдёт ничего, даже если в `.env` лежат боевые токены.
`tests/e2e/isolation.spec.ts` проверяет обе линии на каждом прогоне.

Миграция заводит `admin@tavern.local`, посев добавляет читателей
`reader@test.local` / `second@test.local` и три главы из сгенерированных epub
(`tests/e2e/fixtures.ts`).

## Сценарии

```bash
npm test                 # весь набор, headless
npm run test:ui          # интерактивно: выбрать тест, смотреть шаги
npm run test:report      # html-отчёт последнего прогона
npx playwright test tests/e2e/comments.spec.ts   # один файл
npx playwright test -g "спойлер"                 # по названию
```

Что покрыто: главная и оглавление, вход/выход и защита `next=`, чтение главы и
навигация, редиректы старых адресов, счётчик просмотров, скачивание epub, 404,
комментарии гостя и читателя, спойлеры, ответы с уведомлением через вебсокет,
реакции, удаление админом, профиль (имя, чужое имя, аватарка), игра, панель
администратора и права, телефон (бургер, горизонтальная прокрутка).

Упавший тест оставляет скриншот и трейс в `.data/e2e-results`;
`npx playwright show-trace <trace.zip>` показывает его по шагам.

Добавляя фичу — добавь сценарий рядом. Селекторы предпочитать по роли и тексту
(`getByRole`, `getByPlaceholder`), по классам — только там, где текста нет.

## Исследователь

Два способа запустить — по подписке или по API-ключу.

### По подписке: `/explore` в Claude Code

Без ключа и без счёта за токены — исследователем работает сам Claude Code.
Скилл `.claude/skills/explore/SKILL.md` описывает методику, `.mcp.json`
подключает Playwright MCP (браузер, ограниченный localhost:3100 и шрифтами).

```
/explore
/explore комментарии на телефоне
```

Стенд поднимается сам (`node tests/explorer/stand.mjs` — тот же сервер и
посев, что у e2e), отчёт ложится в `.data/explorer-report.md`. После
добавления `.mcp.json` Claude Code при следующем запуске спросит разрешение
на MCP-сервер проекта — нужно согласиться.

### По API-ключу: `npm run test:explore`

```bash
ANTHROPIC_API_KEY=sk-ant-… npm run test:explore
EXPLORER_STEPS=30 EXPLORER_FOCUS="комментарии на телефоне" npm run test:explore
```

Агент получает браузер (`tests/explorer/browser-tools.ts`: навигация,
aria-дерево, клики по ref, поля, скриншоты, вход под тестовыми аккаунтами,
прямые запросы к API, проверка вёрстки и консоли) и задание найти поломки.
Отчёт — `.data/explorer-report.md`: находки по серьёзности, итог и полный
ход исследования. Критичная находка делает прогон красным.

Стоит токенов (60 ходов ≈ несколько долларов на Opus), поэтому в CI
запускается только руками: Actions → Explorer → Run workflow. Нужен секрет
`ANTHROPIC_API_KEY` в настройках репозитория.

Находки исследователя — повод написать сценарий: воспроизведённый баг
должен остаться в `tests/e2e`, чтобы не вернуться.
